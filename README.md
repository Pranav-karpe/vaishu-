# 💖 Heart Animation for Vaishu ❤️‍🩹

A magical 3D particle heart animation with a romantic Bollywood instrumental tune, glowing golden message, and a shower of love & evil eye emojis.

## ✨ Features
- **3D Particle Transition**: Thousands of glowing particles explode outwards and assemble smoothly into an animated 3D heart.
- **Continuous Radiant Glow & Heartbeat**: Heart stays assembled, pulses with an authentic heartbeat rhythm, and radiates an ambient aura.
- **Golden Glowing Message**: Elegantly reveals *"Thank you so much Vaishu, it means a lot to me ❤️‍🩹"* with shimmering metallic gold styling.
- **Romantic Bollywood Tune**: Features a soulful instrumental track (*Lag Jaa Gale*) with a floating music player button.
- **Love & Evil Eye Rain**: Gentle shower of love emojis and evil eye amulets (`🧿`) cascading continuously from the top.
- **Interactive 3D Orbit Controls**: Rotate, explore, and zoom in/out in real-time.

## 🚀 How to Run Locally
Simply open `index.html` in any web browser, or serve it using Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
